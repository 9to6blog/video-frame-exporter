# FrameDrop — 영상 프레임 추출기

PC에서 영상을 선택한 뒤 **전체 프레임** 또는 **지정한 프레임 구간**을 이미지로 저장하는 Windows용 GUI 프로그램입니다.

## 주요 기능

- 영상을 프레임 단위로 미리보기
- 전체 프레임 추출
- 시작·끝 프레임 지정 추출(양끝 프레임 포함)
- PNG, JPG, WebP 저장
- JPG/WebP 품질 설정
- 진행률 표시와 작업 중단
- 한글 파일명과 한글 폴더 경로 지원
- `frame_000000.png` 형식의 순차 파일명

## 가장 빠른 실행 방법

1. Windows에 [Python 3.10 이상](https://www.python.org/downloads/windows/)을 설치합니다.
   - 설치 화면에서 **Add Python to PATH**를 선택하는 것을 권장합니다.
2. 압축을 풉니다.
3. `run_windows.bat`을 더블클릭합니다.

처음 실행할 때 필요한 패키지를 설치하므로 인터넷 연결이 필요합니다. 두 번째 실행부터는 설치된 환경을 그대로 사용합니다.

## EXE 만들기

`build_windows.bat`을 더블클릭하면 다음 위치에 단일 실행 파일이 생성됩니다.

```text
dist\FrameDrop.exe
```

Python 프로그램을 배포할 PC에는 Python이 없어도 이 EXE를 실행할 수 있습니다. EXE 빌드는 Windows PC에서 진행해야 합니다.

## 사용법

1. **영상 선택**을 누릅니다.
2. 아래 슬라이더로 프레임을 확인합니다.
3. 다음 중 하나를 선택합니다.
   - **전체 프레임**: 영상에 들어 있는 모든 프레임 저장
   - **구간 지정**: 시작·끝 번호를 직접 입력하거나 미리보기의 **현재 프레임** 버튼으로 지정
4. 이미지 형식과 저장 폴더를 정합니다.
5. **프레임 저장**을 누릅니다.

기본 저장 폴더는 원본 영상 옆의 `영상파일명_frames` 폴더입니다.

## 참고

- 프레임 번호는 `0`부터 시작합니다.
- 지정 범위는 시작과 끝을 모두 포함합니다. 예를 들어 `10~19`는 10장입니다.
- PNG는 원본 프레임을 손실 없이 저장하지만 파일 용량이 큽니다.
- JPG와 WebP는 용량이 작지만 설정한 품질에 따라 손실 압축됩니다.
- 매우 긴 영상은 수만 장의 이미지와 큰 저장 공간을 사용할 수 있습니다.
- 일부 특수 코덱 영상은 PC의 코덱 지원 상태에 따라 열리지 않을 수 있습니다.
